# HealthSync AI

### AI-Powered Health & IoT Command Center

HealthSync AI is a ₹0-cost, platform-independent desktop healthcare application that combines:

- Software
- Artificial Intelligence
- Internet of Things (IoT)
- Bluetooth Low Energy (BLE)
- Health data management
- Location-based hospital discovery
- Outbreak analysis

The application is being rebuilt from scratch using Python and PySide6.

---

## Project Objective

HealthSync AI is designed to provide a centralized desktop application for managing personal health information, monitoring IoT sensor data, analyzing symptoms, handling emergencies, discovering nearby hospitals, and viewing outbreak information.
